# Проверка полноты v8

В `OpenRouterInterviewPipelineProvider` перенесены дословные дополнительные
правила coverage из выбранного eval-кандидата v8. Версия в метаданных:
`interview-technical-errors-v8`. Извлечение, фактический judge, модели, схемы,
Unicode-выравнивание и пороги 0,70/0,85 не изменялись. Отклонённый v7 не перенесён.

Правила требуют отдельно проверять независимо запрошенные аспекты, учитывать
краткие содержательные ответы, синонимы и приблизительные числа, не добавлять
неявных требований. Неправильный ответ на аспект считается раскрытием; название
темы без содержания — нет. Уточнены дословные границы цитат пропусков.

## Основание изменения: внешний eval-эксперимент

Измерения выполнены 2026-09-05 в корневом eval-пайплайне рабочего каталога,
вне этого Git-репозитория. Модель: `openai/gpt-5.6-luna`, provider OpenAI.
Split зафиксирован по question_id: 32 ответа / 13 вопросов dev и
14 ответов / 6 вопросов holdout. Все ответы на один вопрос остаются в одной части.
Seed: `luna-generalization-2026-09-05-v1`.

Holdout: q07_fastapi, q10_k8s, q13_redis_cache, q16_migrations,
q18_observability, q19_profiling.

Заранее установлен бюджет двух кандидатов. Критерий выбора на dev:
среднее relaxed F1 спанов с метками и пропусков должно вырасти, ни один из них
не должен снизиться более чем на 0,03. V7 отклонён из-за регрессии спанов.
Выбран v8, меняющий только полноту; holdout запущен после фиксации выбора,
один раз, без последующей настройки. Gold, пороги и метрики не менялись.

| Набор | Версия | F1 спаны + метки, IoU ≥ 0,5 | F1 пропуски, IoU ≥ 0,5 |
| --- | --- | ---: | ---: |
| Dev, 32 | v6 | 0,6087 | 0,5882 |
| Dev, 32 | v7, отклонён | 0,5743 | 0,6316 |
| Dev, 32 | v8 | 0,6087 | 0,6316 |
| Holdout, 14 | v6 | 0,7547 | 0,4444 |
| Holdout, 14 | v8 | 0,7547 | 0,8000 |
| Full, 46 | v6 | 0,6621 | 0,5385 |
| Full, 46 | v8 | 0,6621 | 0,6897 |

Holdout TP/FP/FN пропусков: 2/2/3 → 4/1/1. Предсказания ответных спанов
остались неизменными. Full — описательная сводка, не независимый тест.

Идентификация исходных данных, SHA256:

- Gold: `6a5c2b6e26cd605c5b509b2f6883b9ebb8ce0fbecfc1403dadcd2a9707621c5b`.
- Baseline: `9f93ee785ad7d0379ecfa389c11e519c52afb35da63b718e9308a1b8cdab70e2`.

Оригинальные manifest, selection, предсказания, отчёты и bootstrap сохранены
в `artifacts/luna_prompt_experiment/` соседнего eval-проекта, а не внутри
этого репозитория. Здесь результаты приведены для документирования происхождения
правил; этот коммит не содержит самостоятельного воспроизводимого eval-набора.

## Ограничения

- Примеры ранее уже просматривались/создавались в беседе: holdout ретроспективный,
  не гарантированно неизвестный. После этого эксперимента он раскрыт.
- Всего 6 отложенных тем и 5 gold-пропусков. Парный bootstrap по темам,
  1000 повторов, seed 78123: 95% интервал разности F1 полноты
  [-0,4571; +0,9231]. Статистически убедительное превосходство не установлено.
- Исходные extraction/judge переиспользованы из payload-keyed cache для изоляции
  эффекта полноты; это не исследование вариативности повторных генераций.
- Базовые промпты продуктового провайдера англоязычные и отличаются от внешнего
  eval-пайплайна. Здесь перенесён точный coverage-suffix, но измеренные значения
  **нельзя приписывать этой продуктовой сборке без отдельного сетевого eval**.
- Изменение относится к stateless technical answer evaluation. Отдельный
  `OpenRouterWorkflowAI.analyze`, используемый продуктовым workflow, не изменён.
- Качество спанов и распознавание категории «рекомендуется проверка» этим
  изменением не улучшены. Для дальнейших утверждений нужны новые слепые данные.

## Проверки переноса

Из `backend`:

```bash
python -m pytest tests/providers/test_openrouter_interview.py tests/services/test_answer_evaluation.py
python -m pytest
```

Offline-тесты проверяют отправку v8-правил только в completeness, версию
метаданных, сохранение порогов и дословных Unicode-цитат. Они не проверяют
качество LLM и не заменяют сетевой eval. В рамках переноса сетевой eval не запускался.
